阻抗控制 v5 — 奇异位的两种进入方式

sim 250 Hz 全闭环（aba 被控对象 + 实机量级传感噪声 + URDF 关节限位）· soft 预设 Kx=300 · 门禁 σ≥0.05 才允许开启 · 硬退出 σ<0.02

场景 B｜安全位开启后被推入奇异 全部保持

j4=1.4（σ=0.105）开启 → t=2s 沿径向外推 2s → 松手。问：σ 掉到哪？会不会穿过 0.02 硬退出？松手回得来吗？

曲线
四条水平参考线：σ=0.05 入口门禁（开启时低于此值会被拒绝）、 σ=0.02 硬退出（掉破即放弃阻抗转 PD 抱住）、 σ=0.055 屈肘目标、σ=0.085 屈肘起始。灰色竖带 = 施加推力的时间窗（2–4s）。

场景 A｜直接在奇异位开启（门禁旁路）

把门禁强制旁路，在 j4 从 0.75 一路更伸直的位姿上开启（σ 从 0.063 到 0.013）。问：v5 能不能自己爬出来？

曲线
σ 启动值 < 0.02（j4=0.15）时即刻硬退出——这是设计行为：太深奇异时 Jᵀ 已无法抵抗，抱住最安全。 其余深度 v5 自主屈肘把 σ 拉升 0.01–0.02 并稳住。
