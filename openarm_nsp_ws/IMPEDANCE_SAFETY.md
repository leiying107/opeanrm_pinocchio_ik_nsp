# 阻抗控制安全启动手册

> 适用：`web_panel` 阻抗功能（v3，2026-08-16：抖动修复 + 奇异点三层防护）。
> 原则：**每个参数从最保守值开始，一次只改一个，改完等 10 秒观察再动下一个。**

---

## 0. 抖动事故根因（为什么上次会抖）

上次「打开阻抗就剧烈抖动」，根因按嫌疑排序：

1. **电机侧 kd 非零**（已修复→置零）：v1 给电机发了 `kd=[1,1,0.8,0.8,0.4,0.4,0.4]`。
   DM 电机的速度反馈有量化噪声，任何非零 kd 都会把噪声放大成力矩噪声——
   腕关节惯量只有 ~0.003 kg·m²，±0.5 rad/s 的速度噪声 × kd=0.4 = ±0.2Nm，
   对应数百 rad/s² 的抖动。**已被实机验证平滑的路径是 kp=0、kd=0 纯力矩**
   （零力矩+重力就是这个），v2 严格回到这条路径。
2. **默认档位太硬**（已修复→默认极软）：v1 默认「中」Kx=800N/m。
   v2 默认「极软」Kx=100N/m（10N 只压 10cm，几乎推不动出危险加速度）。
3. **刚度无渐入**（已修复）：v1 开启瞬间满刚度阶跃接入。v2 开启后 2 秒
   smoothstep 从 0 渐升到目标刚度（读数里显示 `渐入xx%`）。
4. **速度滤波不足**（已修复）：速度低通 30Hz→15Hz，阻尼项吃到更多噪声。

**v2 新增保护**（都不可从 UI 关闭）：开启后前 2 秒刚度渐入；阻尼力矩按
关节惯量上限 `|τ_damp,i| ≤ 0.2·I_i/dt` 钳位；‖Δx‖≤10cm 钳位；τ 按 TMAX 钳位。

## 1. 最保守启动参数（照抄）

| 参数 | 最保守值 | 说明 |
|---|---|---|
| 预设 | **极软** | Kx=100 N/m, Kr=3 Nm/rad |
| Kx | **100**（滑条最左） | 位置刚度：推 1mm 要 0.1N |
| ζ | **1.2** | 阻尼比 1.0=临界阻尼，>1 更"黏"更安全 |
| 漏速 | **0.00** | 锚点冻结（回弹模式，不是拖动模式） |
| 重力补偿 | 自动开（scale 1.0） | 开阻抗时自动拉到 1.0，不用手动 |

**安全启动位姿**（开阻抗前把臂摆到这里；⚠️ **左右臂 j2 符号相反**，URDF 肩部关节轴镜像定义，FK 实算：左臂 +0.5 会越过身体中线侵入对侧，右臂 +0.5 才是向外张开）：

| 位姿 | 左臂 (j1..j7, rad) | 右臂 (j1..j7, rad) | 特点（FK 实算 EE 位置） |
|---|---|---|---|
| **自然下垂+肘微弯**（推荐） | `[0, −0.5, 0, 0.8, 0, 0, 0]` | `[0, +0.5, 0, 0.8, 0, 0, 0]` | 臂向外张开在身侧（左EE y=+0.36 / 右 −0.36）、肘前弯、远离奇异与另一臂 |
| 抱胸位 | `[0, −0.6, 0, 1.2, 0, 0.5, 0]` | `[0, +0.6, 0, 1.2, 0, 0.5, 0]` | 同上，肘弯更大，活动空间更封闭 |

j2（肩部侧摆）的作用：① 离开归零奇异位；② 臂张开到身侧，三个方向的推力都可观测。
j4（肘）两臂同号：+0.8 都是向前弯（FK 验证两臂 EE 都前移 +0.155）。

⚠️ **避开三个位姿**：
- **归零伸直位**（全 0）——运动学奇异，Jᵀ 放大误差方向不可控（sim 里也最难看）
- **j2 用错符号**（左臂 +0.5 / 右臂 −0.5）——**臂越过身体中线，侵入对侧臂工作空间，双臂碰撞风险**
- **大范围伸展**（肘≈0 且臂水平指前）——重力矩最大，任何误差都直接甩

摆位方法：**使能→零力矩→托着臂摆到上表位姿→抱住**（全程手不离开臂）。

## 2. 每个参数的含义（完整参考）

### 预设（下拉框）—— 一键刚度组合

| 档 | Kx (N/m) | Kr (Nm/rad) | 直观 |
|---|---|---|---|
| 极软 | 100 | 3 | 海绵。10N 压 10cm；首选/接触未知环境 |
| 软 | 300 | 8 | 弹簧。10N 压 3.3cm |
| 中 | 800 | 20 | 硬弹簧。10N 压 1.2cm |
| 硬 | 1500 | 40 | 接近刚性。10N 压 0.7cm |

选档后 Kx 滑条会跳到该档刚度；**Kx 只管平移**，Kr 是配套的旋转刚度（不可单独调，跟随预设）。

### Kx — 位置刚度（滑条 100–2000 N/m）

末端每偏离锚点 1 米产生的拉回力（牛顿）。`F = Kx·Δx`。
- 越大越"硬"：保持力强、回弹快，但同样误差产生更大力 → 抖动风险越高
- 越小越"软"：顺从性好、安全，但容易被重力/摩擦拉出偏差
- **手感标定**：Kx=100 时，手里放一个 1kg 砝码（≈10N）会把末端压低 10cm

### Kr — 旋转刚度（跟随预设，Nm/rad）

扭转腕部每 1 弧度（57°）产生的回正力矩。含义同 Kx 但作用于姿态。
旋转刚度太硬时扭转抖动最危险（腕关节惯量极小），所以 Kr 上限只到 40。

### ζ (zeta) — 阻尼比（滑条 0.5–1.5，无量纲）

末端运动的"黏滞感"。1.0=临界阻尼（回弹一次到位不振荡）。
- 0.5–0.8：弹跳感（回弹会过冲 1–2 次）——**实机别用，振荡放大风险**
- 1.0：一次到位
- 1.2（v2 默认）：过阻尼，"黏""稳"，**实机推荐**
- 实际阻尼系数由它换算：`Dx = 2ζ√(Kx·m̂)`，m̂=2kg 等效质量
- 注意：阻尼大 = 对速度噪声更敏感（噪声×阻尼=力矩抖动），但受 15Hz 滤波+惯量上限保护

### 漏速 (leak) — 拖动模式强度（滑条 0–2 /s，默认 0）

锚点 x_des 向当前位置"漏"的速率。**0 = 弹簧固定（推完回中）；>0 = 柔顺拖动**。
- 0：纯保持。推开后松手回弹到原位
- 0.3–0.8：示教手感。推到哪里停住，锚点慢慢跟上来，几秒后"停"在新位置
- 1–2：接近零力矩的"漂浮"（仍有阻尼兜底）
- 换算：漏速 λ 时锚点时间常数 ≈ 1/λ 秒（0.5 → 2 秒跟上）

### 渐入 (ramp，只读)

开启后 2 秒内刚度从 0 平滑升到目标值（读数显示 `渐入xx%`）。防开启瞬间
满刚度阶跃激励。不可调；重新开启（取消勾选再勾选）会重新渐入。

### 其它不暴露在 UI 但起作用的量

| 量 | 值 | 含义 |
|---|---|---|
| DX_MAX | 10cm | Δx 钳位——弹簧拉伸超过 10cm 后力不再增大 |
| DTH_MAX | 0.5 rad | 姿态误差钳位（29°） |
| QDOT_SOFT | 3 rad/s | 关节超速时只衰减弹簧力（阻尼保持满额灭火） |
| TMAX | 54/54/28/28/10/10/10 Nm | 每关节力矩钳位（DM8009×2, DM4340×2, DM4310×3） |
| KD_J | 关节阻尼底噪 | 指令内的关节阻尼（受下面上限保护） |
| 0.2·I/dt | 阻尼钳位 | 按关节惯量限制阻尼力矩，防采样失稳（腕 I≈0.003） |

## 3. 安全启动流程（照步骤走）

```
准备     清场 → 人站侧方 → 一手可及"失能"按钮 → 托臂习惯
启动     ros2 run openarm_dashboard web_panel   (确认 [panel] ▶ READY)
回归     勾重力补偿 scale=1.0 → 托臂抬起松手 → 悬停确认（§14 行为）
摆位     使能(零力矩) → 托臂到 左[0,-0.5,0,0.8,0,0,0]/右[0,+0.5,...] → 抱住
核对     阻抗行参数 = 极软 / Kx=100 / ζ=1.2 / 漏速=0.00 （不符先改）
开启     手轻扶末端 → 勾选「阻抗」→ 数日志：自动开重力 → 渐入2秒
观察     10 秒静置：无抖动、无异响、q̇max<1、‖Δx‖<3cm → 通过
体验     轻推 → 回弹 → 换方向 → （都稳定才）下一档
调参     一次一个：先 ζ(0.5步) → 再 Kx(×2步) → 最后漏速
退出     取消勾选 → 抱住当前位姿；急退 = 失能（先托臂！掉电即落）
```

**逐级加硬路线**（每级观察 10 秒）：极软 → 软 → 中 → 硬；Kx 滑条微调时 ±100 一格。

## 4. 立即中止条件（任一 → 取消勾选或失能，托臂）

1. 静止时任何可见抖动 / 持续蜂鸣 / q̇max > 2 rad/s 不回落
2. ‖Δx‖ 顶死 10cm 钳位不回落
3. 关节突跳、异响
4. MOS 温度 > 70°C（面板红）
5. 日志连续出现 `阻抗计算超时/异常 → 抱住`

**抖动应急口诀**：先勾掉阻抗（回电机 PD 抱住，最快）→ 不行再失能（掉电，先托臂）。

## 5. 参数风险速查

| 想调 | 往哪边安全 | 为什么 |
|---|---|---|
| 更硬 | 逐级、小幅 | 刚度↑ → 同误差力↑ → 抖动/发热风险↑ |
| ζ | 先加后减 | <1 会弹跳振荡；只有确认无抖才试 <1 |
| 漏速 | 从 0.3 起 | 高漏速≈零力矩，臂会缓慢滑垂（重力误差累积） |
| Kx 滑条 | ≤1000 起步 | >1000 只在软/中档验证过手感后用 |

## 6. 奇异点防护（v3 新增，三层）

阻抗用 Jᵀ 映射力（有界，不会力矩爆炸），但奇异方向上弹簧"消失"——漂移无界、
F_est 低报、可能无声肘翻转。三层防护（σ_min = 6×7 雅可比最小奇异值，阈值来自
工作空间采样：中位数 0.078）：

| 层 | 触发 | 行为 |
|---|---|---|
| **入口门禁** | 开阻抗时 σ<0.05 | **拒绝开启**，日志提示"先屈肘(肘≈1.2rad)" |
| **软逃逸** | 运行中 σ<0.05 | 零空间姿态目标混合偏向屈肘位 [j4→1.2]（EE 由弹簧保持，肘主动爬出奇异方向）；越深拉力越强（0.02–0.05 线性渐变） |
| **硬退出** | σ<0.02 | 退出阻抗→电机侧 PD 抱住（与看门狗同路径） |

UI 读数新增 `σ x.xxx`，<0.05 显示 ⚠奇异。

**为什么逃逸方向是屈肘**：j4 不镜像（两臂 + 都向前弯，FK 验证），σ 随 |j4| 单调
上升（伸直=0 → j4=2 时 0.132），屈肘对两臂都是逃逸方向。

**sim 验证**（j4=0.8 开启 → 强制把姿态目标设为伸直臂）：
q4 被拉到 0.60、σ 降到 0.050 边界时软逃逸接管，q4 稳住不再降，全程无硬退出、
EE 不动。奇异数值：j4=0.5→σ0.042 / 0.6→0.051 / 0.7→0.059（门禁在 0.05 会拒开）。

## 7. 调试日志（出问题后的 post-mortem）

面板自动落盘三路日志到 `<workspace>/log/panel_<日期时间>/`（无需任何配置，启动即记录）：

| 文件 | 内容 | 用途 |
|---|---|---|
| `panel.log` | 所有面板消息（模式切换/门禁拒绝/看门狗/过热）带时间戳 + 启动横幅（关键文件 mtime） | 发生了什么事件、什么顺序 |
| `commands.jsonl` | 每次 HTTP 点击（模式/重力/阻抗/滑条参数/推力）带时间戳 | 你**何时点了什么** |
| `ctrl_left/right.csv` | **250Hz 全量控制环**：t, 模式, 使能, 重力, q[7], q̇[7], τ实测[7], τ指令[7], 温度[7], dx, fest, σ, ramp | 抖动/异常的波形证据 |
| `can_stats.jsonl` | 每 5s 的 CAN 收发/错误计数器（仅实机） | CAN 掉线/误码排查 |
| `event_<side>_<时间>.csv` | **看门狗/奇异硬保护/过热/退出阻抗触发时**自动保存事发前 5 秒控制数据（首行 # reason） | 事故现场快照 |
| `ring_tail_<side>.csv` | 进程退出时自动保存最后 30 秒控制数据 | 崩溃/被 kill 也不丢 |

设计保证：控制环线程只做 `queue.put_nowait`（内存操作），CSV 由**独立写盘线程**负责——
4ms 循环绝不被磁盘 IO 阻塞；写盘跟不上只丢行并在日志里报告（`记录丢弃 N 行`）。

**出问题后的操作**：
```bash
cd /ros2_ws/openarm_nsp_ws
ls -dt log/panel_* | head -3                      # 找到那次会话
tar czf /tmp/debug_$(date +%H%M%S).tar.gz log/panel_<时间>/

```

（τ 是否顶 TMAX、σ 是否掉进奇异区）→ `event_*.csv` 看退出瞬间的波形。

## 8. 「阻抗计算超时」事故分析（2026-08-17 实机，已修复）

**现象**：开阻抗 1–2 秒后退出，日志 `阻抗计算超时(>8ms) → 抱住`，重开必复现。

**日志证据**（250Hz CSV）：tick 间隔 p50=4.1ms 正常，**p99=10ms**——1134 tick 里 31 个
（2.7%）偶发超 8ms；看门狗"单次超时即熔断"→ 按 2.7% 尖峰率，存活 450 tick（1.8s）
后必然撞上一次。温度 28.9°C 排除过热。**不是算法慢（空载 0.17ms），是偶发延迟尖峰。**

**尖峰根因**（两个都在 Python/numpy 生态里，非算法）：
1. **OpenBLAS 线程池**：SVD/solve 在 8 核 RK3588 上默认多线程，跨核自旋同步与
   SSE/写盘/另一臂线程争核时偶发 5–15ms 停顿（实时系统经典问题）
2. **Python GC**：250Hz×2 臂的数组分配 + 环形缓冲，gen2 全量回收毫秒级随机停顿

**修复**（三件套，均已验证）：
1. **BLAS 单线程**（启动时设 OPENBLAS/OMP_NUM_THREADS=1）：6×7 矩阵单线程只要
   ~0.1ms，彻底消除线程池同步停顿
2. **GC 冻结+禁用**（gc.freeze()+disable）：引用计数照常回收我们分配的所有数组
3. **看门狗改连续 3 次超时才退出**：单个 4ms tick 偶发延迟对纯力矩控制无害
   （无积分项），连续 3 次（>12ms 无更新）才是真卡死

另外每 tick 的 FK 从 2 次合并为 1 次（`_pose_and_jac` 一趟出位姿+雅可比）。

**修复后压测**：4 线程 CPU/磁盘争抢下 5000 次 torque()，p99=1.3ms、max=6.1ms、
超 8ms = 0 次（修复前实机 p99=10ms、2.7% 超时）。

## 9. 第二轮实机（2026-08-17 10:25）：超时残留根因 + 「大力回弹」定性

**超时**（存活延长到 36–138s，但 p99.9=24.6ms 尖峰仍在）：上一轮的
OPENBLAS_NUM_THREADS=1 **没有生效**——numpy 在 import 时已把 OpenBLAS 线程池定成
8 线程，之后设环境变量无效；真正能运行时压线程的 threadpoolctl 当时未安装且
静默跳过。**修复**：安装 threadpoolctl + `threadpool_limits(1)` 强制限制活线程池
（验证：池 8→1，SVD p99=0.018ms）。

**大力回弹**（推到极限时）：250Hz 数据定性——退出确实抱住的是**当前位姿**
（距退出位形 ≤0.006 rad，没有"回原位"路径），但超时窗口（连续 3 次 ≈91ms 无更新）
里**阻尼消失、臂被继续推着加速**，退出瞬间腕速度已达 11–20 rad/s；随后电机侧
PD(kp=70) 立即全力刹车 → 冲过头（j5 越过抱住点 1.6 rad）→ 被拉回 = 感受到的
"大力回弹"。**责任链：BLAS 尖峰→阻尼停摆 91ms→高速→PD 硬刹过冲。**

**修复**：退出时若 |q̇|>2rad/s，进入 0.5s「阻尼刹车窗」——PD 之上叠加
受采样稳定上限保护的纯力矩关节阻尼，让减速柔和而不是阶跃硬刹（日志会打
`退出时高速(x.x rad/s) → 0.5s阻尼刹车`）。根因修复（BLAS 单线程）落地后该场景
本身应不再出现，刹车窗是纵深防御。

## 10. 第三轮实机（2026-08-18 07:18）：15Hz 振荡事故分析与修复

**现象**：前 6 次开启全部正常（含 3.5 分钟稳定保持），最后一次（07:26:56，
soft 档）开启 5 秒后严重振荡，看门狗超时退出。

**日志审计结论**：
- ✅ BLAS 修复生效：成功段 47055 tick，p99=5.5ms、p99.9=6.9ms（上轮 24.6/91ms）
- ✅ 关节限位 trip-wire 6 次全部正确触发，从未触碰机械硬限位
- ✅ 入口门禁 12 次正确拒绝伸直位
- ✅ 事件快照/看门狗兜底正常

**振荡证据链**（event_right_072703.csv）：
1. 开启位形 σ_min=0.057 贴着门禁（此前成功几次 0.09–0.11）
2. 全程 σ 徘徊 0.052–0.058 —— **骑在软逃逸阈值 0.05 上**
