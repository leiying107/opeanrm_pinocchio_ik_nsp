# OpenArm 笛卡尔 6D 阻抗控制 —— 原理与实现

> 版本 2026-08-18。对应代码：`openarm_dashboard/impedance.py`（控制律）、
> `arm_controller.py`（IMPEDANCE 模式集成）、`web_panel.py`（HTTP/UI）。
> 安全操作与调参见 `IMPEDANCE_SAFETY.md`；本文只讲原理与实现结构。

---

## 1. 要解决的问题

让机械臂末端呈现**可调的弹簧-阻尼特性**：手推 → 顺从让开；松手 → 回弹（或拖住）；
无力传感器时还能从偏差反推接触力。与"位置控制"（指哪必须到哪）相对，
阻抗控制（impedance control）控制的是**末端对外表现出的力学特性**——
刚度 K、阻尼 D 由参数设定，不依赖力测量。

OpenArm v1.0 双臂、7 关节/臂、DM 电机 MIT 模式（`τ = kp(q_des−q) + kd(dq_des−dq) + τ_ff`）、
无力传感器。阻抗以 **kp=kd=0 的纯力矩前馈** 实现——与实机已验证的
"零力矩+重力补偿"完全同一条执行路径，这是选择该方案的核心依据。

## 2. 控制律（每 tick 一次，250 Hz）

输入：q（7 关节角）、q̇（7 关节速度反馈）、dt。输出：τ（7 关节力矩，**不含重力**）。

```
速度滤波   q̇_f ← 15Hz 一阶低通(q̇)                      # 压电机量化噪声
FK+雅可比  (oMf, J) = _pose_and_jac(q)                  # 一趟同时出末端位姿和 6×7 雅可比
           （世界对齐系 LOCAL_WORLD_ALIGNED，x前 y左 z上）
奇异监护   σ = σ_min(J)                                  # SVD 最小奇异值
漏速更新   f = 1−exp(−leak·dt);  x_des += f·(x−x_des)    # leak>0 时锚点跟随（拖动模式）
误差       Δx = x_des − x          （钳位 ‖Δx‖ ≤ 10cm）
           Δθ = log₃(R_des·Rᵀ)     （钳位 ‖Δθ‖ ≤ 0.5rad）
速度映射   ẋ = J[:3]·q̇_f,  ω = J[3:]·q̇_f
弹簧-阻尼  F = s·ramp·Kx·Δx − Dx·ẋ                       # Dx = 2ζ√(Kx·m̂), m̂=2kg
           T = s·ramp·Kr·Δθ − Dr·ω                       # Dr = 2ζ√(Kr·Ĩ), Ĩ=0.05
任务力矩   τ_task = J[:3]ᵀ·F + J[3:]ᵀ·T                  # 虚功原理：Jᵀ 把末端力映射为关节力矩
零空间     N = I₇ − J⁺·J  （J⁺ 阻尼伪逆）
           τ_null = Nᵀ·( s·ramp·Kq·(q_target−q) − Dq·q̇_f )
发送       τ_total = clip( τ_task + τ_null − KD_J·q̇_f + G(q), ±TMAX )
           MITParam(kp=0, kd=0, 0, 0, τ_total)            # 纯力矩
```

### 2.1 各项的物理意义

| 项 | 意义 |
|---|---|
| `JᵀF`（任务弹簧+阻尼） | 末端 6D 弹簧：把"末端受力 F"按虚功原理翻译成关节力矩 |
| `Nᵀ`（零空间投影） | 7 关节控 6 维任务，剩 1 个冗余自由度（肘摆动）。姿态弹簧只在 N 内作用：**末端被任务弹簧锁住，肘部可独立软动**（实测：沿零空间推肘 0.2rad，末端仅动 1.4mm，肘部等效刚度 12.5 Nm/rad） |
| `G(q)` | 重力前馈（pinocchio 在 v1_simple.urdf 上算，与 KDL/MuJoCo 数值一致）。阻抗模块自身**不含重力**——两者相加、无重叠，这是与已验证重力补偿共存的结构保证 |
| `KD_J·q̇` | 关节阻尼底噪，兜住 Jᵀ 阻尼在奇异方向漏掉的成分 |

### 2.2 弹簧与阻尼的不对称保护（承重设计）

`τ_spring` 与 `τ_damp` 分开计算、分开施加保护：

| 保护 | 弹簧 | 阻尼 |
|---|---|---|
| 开启 2s 渐入 ramp | ✓ | ✗ 首tick满额 |
| 超速衰减（q̇>3rad/s, s=3/q̇max） | ✓ | ✗ 永不衰减 |
| 采样稳定钳位 \|τ\|≤0.2·I_i/dt | ✗ | ✓ 强制 |
| TMAX 终钳 | ✓（合并后） | ✓（合并后） |

原则：**弹簧管"停在哪"（可以削），阻尼管"别振荡"（不能削但有物理上限）**。
两次实测教训支撑：衰减阻尼 → 腕部 13 rad/s 自激极限环（高速削弱了正在灭火的
阻尼）；不钳阻尼 → ZOH 采样失稳（稳定边界 kd·h/I<2，腕惯量仅 0.003 kg·m²）。

### 2.3 参数表

| 参数 | 范围/默认 | 作用 |
|---|---|---|
| Kx 位置刚度 | 100–2000 N/m | 弹簧硬度；F=Kx·Δx，10N 推力的位移=10/Kx |
| Kr 旋转刚度 | 跟随预设 3–40 Nm/rad | 姿态弹簧 |
| ζ 阻尼比 | 0.5–1.5，默认 1.2 | 一个旋钮换算全部阻尼 D=2ζ√(K·m̂)；>1 过阻尼 |
| leak 漏速 | 0–2 /s | 锚点跟随时间常数 1/λ；0=回弹模式，>0=拖动模式 |
| ramp 渐入 | 固定 2s | smoothstep 0→1，防开启瞬间满刚度阶跃 |
| 预设 | 极软/软/中/硬 | (Kx,Kr) = (100,3)/(300,8)/(800,20)/(1500,40) |
| 零空间 Kq | [20,20,20,15,5,5,5] Nm/rad | 肘部姿态弹簧 |
| Δx/Δθ 钳位 | 10cm / 0.5rad | 弹簧力封顶（Kx×0.1），超程变"恒力让位" |
| QDOT_SOFT | 3 rad/s | 超速只撤弹簧 |
| TMAX | [54,54,28,28,10,10,10] Nm | DM8009×2/DM4340×2/DM4310×3 |

## 3. 模式机集成（arm_controller.py）

```
DISABLED ──enable──> ZERO_TORQUE ──hold──> ENABLED_HOLD ──勾选阻抗──> IMPEDANCE
                        │                                          │
                        └──────────────勾选阻抗─────────────────────┘
任何模式 ──disable──> DISABLED          IMPEDANCE ──取消勾选──> ENABLED_HOLD
```

- **入口门禁**：开阻抗时算 σ_min，<0.05 拒绝（奇异位弹簧失效），日志提示屈肘
- **进入即自动开重力**（scale 拉到 ≥1.0）：无重力的弹簧要扛自重，Δx 失真
- **锚点捕获**：开启瞬间的位姿即 x_des/R_des/q_post（所以要在静止、想要的位姿开启）
- **切换力矩连续**：从 hold 进入时 PD 稳态 ≈ G(q)，阻抗首 tick ramp≈0、τ≈G(q)，无跳变
- **在线调参不重锚**：滑条只改参数；重新勾选才重新捕获锚点+重新渐入
- **退出**：取消勾选/奇异硬保护/看门狗 → 抱住**当前**位姿（`_hold_q = q_now`）；
  若退出时 |q̇|>2rad/s 进入 0.5s 阻尼刹车窗（PD 上叠受钳位纯力矩阻尼，渐停防过冲回弹）
- **运动请求自动接管**：归位/回起点/到终点/直线/弧线会先退出阻抗

### 3.1 归位与阻抗的关系（常见疑问）

归位（HOMING）**不用阻抗**：`MOVE_DUR=2s` 关节空间线性插值 q_des(t)，每 tick 喂
电机侧 PD `τ=kp(q_des−q)−kd·q̇+G(q)`（kp=70/70/70/60/10/10/10）。即"插值器出轨迹、
PD 跟踪"，与阻抗互斥；从阻抗发起归位会自动先退回 hold 再开始插值。

## 4. 奇异点防护（v5：方向感知 + 主动屈肘）

Jᵀ 有界（不像伪逆 J⁺ 会爆），奇异点不会力矩爆炸——真正的失效是**弹簧在奇异
方向消失**（Jᵀ 把该方向力映射为 0）→ 无界漂移、F_est 低报、可能无声肘翻转。

**关键事实：奇异是方向性的。** 伸直手臂时只有径向（肩→手连线）失控，
其余 5 个任务方向完全可控（实测 |u_min·径向| = 0.999–1.000；σ<0.06 的随机
位姿中 95% 径向对齐）。因此 v5 不再把 σ_min 当标量一刀切，而是：

### 4.1 任务空间方向加权 W

每 tick 对 J 做带向量的 SVD（p99 增量 ~0.05ms），构造

```
w_i = σ_i² / (σ_i² + SIG_DIR²)         (SIG_DIR=0.05)
W  = U · diag(w) · Uᵀ                   (6×6)
τ_task = Jᵀ(K·W·Δ − D·W·ẋ)
```

σ_6 掉到 0.02 时**径向**弹簧/阻尼平滑衰减到 ×0.14，其余 5 个方向满刚度——
低 σ 位姿侧向依然柔顺（T7 实测：σ=0.057 时侧推 20N 让位 68mm≈理论 67mm）。
fest 同样用加权后的 Δx——不含被冻结方向的假想力，读数诚实。

### 4.2 主动屈肘（速度化解的折叠控制）

折叠方向 **v_dir = Vt[5]**（最小奇异值对应的关节方向 ≈ j1+j4 耦合"折臂"；
注意 Vt[6] 是精确零空间的肘回旋方向，与 Vt[5] 正交——别用错）。沿 v_dir
运动时末端几乎不动（‖J·v_dir‖=σ_6），所以屈肘**不激怒任务弹簧**。

控制律是**纯速率形式**（压测教训：一切位置/力形式的屈肘力矩都不稳定——
开环恒力在腕部激励 70Hz 振颤；饱和大力+滞后阻尼产生极限环；margin 缩放
的力又扛不住 50N 推力。速率律一次解决全部）：

```
σ̇_ref = −K_SIG · min(0, σ − SIG_HOLD) · boost     (σ≥SIG_HOLD 时为 0)
σ̇    = LPF₅Hz(dσ/dt)                              (实测 σ 变化率)
τ_flex = v_dir · sgn · C_SIG · (σ̇_ref − σ̇) · blend · drag_gate
```

- σ 高于 SIG_HOLD：只**阻尼**折叠运动（防加速冲向奇异）
- σ 掉到 SIG_HOLD 以下：命令有界的"折出"速率，把 σ 拉回
- 输出只与**速率误差**成正比 → 不会激励任何位置共振；高增益无振颤
  （C_SIG 从 3 扫到 60，静态振幅不变 0.0008 rad）
- drag_gate：当 EE 位移方向表明是屈肘自己在拖动 EE（对准判据）时交还
  权限给任务弹簧——外力推压弹簧时**不**衰减（方向可分辨两种 |dx| 来源）

实测行为（sim 250Hz 全闭环 + 传感噪声）：

| 场景 | 结果 |
|---|---|
| 径向外拉 30/50N | σ 被托在 0.036–0.049 不触硬退出，松手回 0.074 —— **软挡块** |
| 沿臂轴向内推 50N | q4 1.8→0.96 主动屈肘让位（像人臂被顶），σ 始终 >0.07 |
| 伸直附近侧向推 20N | 正常柔顺（好方向不受影响） |
| 软挡块边界悬停 3s | 无 hunting（j7 过零 0 次） |

### 4.3 防护层总表（v5）

| 层 | 触发 | 行为 |
|---|---|---|
| 入口门禁 | 开启时 σ<0.05 | 拒绝开启（防在奇异位起锚） |
| 方向淡化 | σ<0.05 渐变 | W 矩阵把**径向**弹簧/阻尼平滑衰减，其余方向照常 |
| 折叠控制 | σ<0.085 渐变 | 速度化解屈肘力矩：阻折叠、必要时主动折出 |
| 硬退出 | σ<0.02 | 退出阻抗 → 关节 PD 抱住（预期不再触发，兜底保留） |

参数（impedance.py）：SIG_DIR=0.05, SIG_BLEND_HI=0.085, SIG_HOLD=0.055,
SIG_DEAD=0.012, K_SIG=2.5/s, C_SIG=30 Nm·s, K_PUSH_BOOST=3, V_DIR_LPF=15Hz,
VFOLD_LPF=5Hz, BLEND_SLEW=0.04/tick。压测调参依据见 §8.1。

## 5. 极限与饱和行为（"弹簧崩断"问题）

不存在断崖，是**渐次接管的饱和链**，每层饱和后输出仍确定：

```
推力↑ → 线性弹簧（F=KxΔx）
     → Δx=10cm：弹簧力封顶 Kx×0.1（极软10N…硬150N），恒力让位
     → q̇>3rad/s：弹簧按 3/q̇max 衰减（防甩），阻尼满额拖行
     → 关节 τ 到 TMAX：该关节封顶（重力优先，阻抗余量缩水）
     → σ<0.05：肘部软逃逸
     → σ<0.02：硬退出 → 关节 PD（比弹簧硬一个量级）抱死
```

无积分项 → 无 windup：饱和不累积，撤力即恢复。最坏体验 = 恒力让位 →
突然变硬墙（PD），不存在"崩断自由落体"路径。

## 6. 实现结构与线程模型

单进程多线程（web_panel 进程）：

```
uvicorn 事件循环     HTTP 端点（/impedance 等）+ SSE 20Hz 快照
arm-{left,right}     250Hz 工作线程：recv CAN → 算 τ → 发 MIT → 记录行入队
rec-{left,right}     写盘线程：queue 取行写 CSV（控制环只 put_nowait，永不碰盘）
can-sampler          5s 一次 CAN 计数器
规划线程             弧线/直线/B样条点击时临时 spawn
```

- 命令路径：浏览器 POST → handler → `queue.Queue` → 臂工作线程执行（**CAN 调用
  全部收敛在工作线程**，Web 层不碰 CAN）
- 状态路径：工作线程写 RobotState（锁保护快照）→ SSE 读快照推送
- GIL 不构成瓶颈：numpy/pinocchio 在 C 层执行释放 GIL，双臂线程真并行
  （实测双臂同跑 tick p50=4.1ms）

### 6.1 实时性保障（两轮实机事故的产出）

250Hz 循环的延迟尖峰曾被 OpenBLAS 线程池同步（8 核 RK3588 上 5–90ms）和
Python gen2 GC 停顿打断，导致看门狗熔断。现启动时执行 `_realtime_hygiene()`：

1. **threadpoolctl.threadpool_limits(1)**：把 numpy import 时已定死 8 线程的
   OpenBLAS 池强制压到 1（6×7 矩阵单线程 0.015ms，多线程毫无收益只有同步害处）。
   ⚠️ 仅设 `OPENBLAS_NUM_THREADS=1` 环境变量**无效**——numpy import 后池已定型
2. **gc.freeze() + gc.disable()**：对象无循环引用，引用计数照常回收，禁用
   周期性全量回收的 stop-the-world 停顿
3. **看门狗 3 连超时**：单 tick 偶发延迟对纯力矩无害（无积分），连续 3 次
   （>12ms 无更新）才退出

修复后压测：4 线程 CPU/磁盘争抢下 5000 次 torque()，p99=1.3ms、max=6.1ms、
超 8ms=0 次。**不要把 BLAS 改回多线程**。

## 7. 接触力估计（无力传感器的 F_est）

`F_est = Kx·Δx`（弹簧认为的接触力），sim 验证：施加 20N → F_est=19.3N
（误差 3.5%）。局限：不含静摩擦（实机死区几 mm 内低估）、Kx 误差直接传递。

### 8.1 暴力压测（v4 → v5 的验收依据）

`test_impedance_stress.py`：5 层 ×2084 场景（8 分片并行，单线程 BLAS——
多线程 BLAS 的 SVD 约简不确定性会被不稳定回路放大成不同结论）：
L1 位姿网格×推力方向×力度（1800）、L2 有趣位姿×预设×ζ×力度（96）、
L3 随机 fuzz 多段推力+中途调参+tick 抖动（60）、L4 撤力回弹（80）、
L5 轴向内推酷刑（48）。判定：OK / DRIFT / OSC / SIGEXIT / FATAL。

| 判定 | v4 基线 | v5 | 说明 |
|---|---|---|---|
| OK | 464 (22%) | 1139 (55%) | |
| OSC | 1435 (69%) | 402 (19%) | 剩余集中 mid ζ=1.4（v4 已有，ZOH 边缘；实机有超速绊线兜底） |
| SIGEXIT | 173 (8%) | 61 (3%) | 剩余为 fuzz 极端位形 |
| DRIFT | 12 (1%) | 482 (23%) | 见下注 |
| L5 轴向内推 | 8/48 OK | **48/48 OK** | v5 屈肘让位全部通过 |
| L4 撤力回弹 | 34/80 OK, 46 OSC | 60/80 OK, **0 OSC** | 回弹振荡消除 |

DRIFT 注：v4 把这些场景判为 OSC（不稳定）；v5 稳定但有偏移——根因是
**软预设下姿态弹簧穿过弱任务弹簧拖动 EE**（ultra Kx=100 只能拉 10N，
NULL_KQ=15–20 的姿态力把它拖到 DX_MAX 附近）。该行为 v4 同样存在，只是
被振荡掩盖。对策：需要末端保真时用 mid+ 预设（§2.3 已注明）。

压测抓出并修复的设计错误（sim 先行验证的价值所在）：
开环恒力屈肘→腕部 70Hz 振颤；屈肘阻尼绕过 ZOH 上限→71Hz 共振；
blend 带 0.12 过宽→健康位姿 (σ=0.07) 97mm 永久偏移；SIG_HOLD 过高→
弹簧平衡点卡在目标下方 0.001 的僵局；无关节限位被控对象→假 SIGEXIT。

## 9. 已实机验证的关键数字

| 项 | 值 |
|---|---|
