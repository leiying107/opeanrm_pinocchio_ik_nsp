# OpenArm 自碰撞检测与避障规划 — 设计与验证报告

> 版本 2026-08-20。模块：`openarm_pinocchio_nsp/collision.py`（检测核心）、
> `collision_ik.py`（零空间让位 IK）、`collision_planner.py`（三策略避障规划）、
> `bimanual_planner.py`（14 维双臂协同 B 样条）、`validation/v_collision_suite.py`（验证套件）。
> 全部纯计算（Pinocchio 3.9.0 内置 hpp-fcl 2.4.5），不含 CAN/电机代码，在 venv 内运行。

---

## 1. 背景与结论

**改造前**：所有规划路径（直线/弧线/回放/到终点）**均无任何自碰撞检测**；
`bspline_planner.py` 是唯一有碰撞项的模块，但只检查单臂自身对，**左右臂互碰（95 对）
和臂-基座碰撞（14 对）从未被检测过**，且其邻接过滤规则有 bug（按 joint-id 数值差过滤，
肩壳-上臂这类真危险对被误保留/真该查的对被丢弃）。

**改造后**：三层能力全部落地并通过仿真验证（15/15 套件用例 + 40 随机场景压力测试 0 失败）：

| 层 | 模块 | 能力 | 实测 |
|----|------|------|------|
| 检测 | `collision.py` | 双臂全对（163 对：单臂 54 / 跨臂 95 / 臂-基座 14），20mm 安全边距 | 0.3–1.7 ms/次 |
| 让位 | `collision_ik.py` | IK 解在零空间（肘部摆动 1-DoF）上滑移避障，**末端路径不变** | +0.1–1s/解 |
| 绕行 | `collision_planner.py` | 中段遇障 → 垂直偏移绕行（递归分层）；终点不可达 → 安全截断 | 0.6s/规划 |
| 协同 | `bimanual_planner.py` | 14 维（双臂 7+7）B 样条 SLSQP 优化，跨臂碰撞罚项全程生效 | 2–3s/规划 |

## 2. 检测核心要点

- **对集构造**：全对 207 → 运动学树祖先（2 级）去邻接 → 同夹爪双指去除 → **163 对**。
  分类：`arm_self`（54）/ `cross_arm`（95）/ `arm_body`（14）。
- **性能关键**：带 20mm 边距的布尔检测比零边距**更快**（GJK 提前终止）；
  精确距离查询（mesh-mesh）~190ms 只用于离线报告。
- **边距 API 陷阱**：`setSecurityMargins` 接受 `(n_geom, n_geom)` 矩阵按几何体 id 索引，
  不是按碰撞对——已封装在 `BimanualCollisionChecker._cdata`（按边距值缓存）。
- **标定结论**（对 URDF v1.urdf，21 个碰撞体）：
  - 零位（归零位姿）20mm 边距下干净，最近真实对 33.7mm（link0↔link3）。
  - 肩部 j2 内折的碰撞边界（20mm）：左臂 j2 ≤ 0.252 rad（14.4°）；URDF 限位 0.1745
    ——但**腕/手指在 j2 限位附近即可违反**（link6/finger vs body），故 body 对必须保留。
  - 随机限位内双臂位姿约 8% 违反 20mm 边距（主要是臂-基座对）。

## 3. 让位 IK（零空间推斥）

7-DoF 控 6D 任务 → 零空间 1 维 = 肘部摆动（self-motion 流形）。DLS 收敛后若净距
低于 comfort（40mm），沿流形采样 24 点（每点重投影防漂移），选满足 EE 预算（2mm）
且净距最大的点。**注意**：投影矩阵 P 在 J 零空间上特征值是 1（不是 0），
零空间方向 = P 的**最大**右奇异向量（实测取 argmin 会拿到任务方向，|J·n|≈1.75）。

## 4. 三策略避障规划

```
plan_line_quat(pos_s, quat, pos_e, q_init)
  ├─ 0 干净：直接返回
  ├─ 1 零空间让位：仅迁移违例样本（路径不变，最快）
  ├─ 2 绕行：中点垂直偏移 via 点（±方向 × 3 距离），两段分别验证后拼接
  │     （第二段锚定在第一段实际终点 FK，防内部递归错位）
  └─ 3 截断：返回碰撞前前缀 + 诊断（终点本身在障碍内时的正确行为）
```

## 5. 双臂协同（14 维 B 样条）

控制点 = 14 向量（左 7 + 右 7 同步优化）。代价 = 跟踪 + 平滑 + 碰撞阶梯罚
（30/20/10mm 三档布尔检测）。端点 3D 位置 IK 用 **LOCAL_WORLD_ALIGNED** 雅可比
（LOCAL 系做位置 IK 会把步进方向转错）。`time_budget` 参数限制墙钟（ARM 板
SLSQP 数值梯度 ~0.5s/迭代）。

**物理边界实测**：双臂腕部对向汇合（工具朝向同侧）时，EE 间距 ≤200mm 必碰
（link6/link7/手指跨臂对）；240mm 间距干净（最近 54mm）。双臂交接任务应以此为最小间隙。

## 7. 性能优化记录

规划器从 18.1s → 0.6s（30 倍）：本板 OpenBLAS（NEOVERSEN1, 8 核）对 6×6 矩阵
`solve(A, I)`（矩阵逆）比 `solve(A, v)`（单向量）**慢 250 倍**（2ms vs 8µs，线程
同步开销）。修复：`ik_nsp.py` 新增 `damped_pinv_matvec`，`kinematics.py` 的
Stage-1 DLS 与 Stage-2 零空间投影改为单向量求解（`P v = v − J^#(Jv)`）。

## 8. 实机接入（web_panel，2026-08-21 完成）

### 架构：共享 gate + 分级策略 + fail-open

```
openarm_dashboard/collision_gate.py   ← 单例 CollisionGate
    ├─ 唯一 BimanualCollisionChecker（启动后台构建 ~1.4s，失败→fail-open）
    ├─ gate_config(side, q, label)        静态构型门（回起点/弧线回起点/到终点）
    ├─ gate_trajectory(side, path, label) 轨迹门（弧线/回放/B样条）
    ├─ 5Hz 监护线程（250Hz 循环之外，~0.4ms/次）
    │    拖动/零力矩/阻抗模式的红牌+日志——只告警绝不掉电（手在环）
    └─ 对侧臂始终以其实测 q 参与（单臂操作 vs 停靠臂的正确模型）
```

**分级策略**（用户已确认）：

| 入口 | 策略 |
|---|---|
| ▶直线运动 | **完整避障**：CollisionAwarePlanner（让位→绕行→截断前段） |
| ▶弧线IK / ▶关节回放 / ▶B样条 | 让位（保示教形状）→ 仍违规**拒绝**+日志给碰撞对 |
| ▶到终点 / ↩回起点 / ↩弧线回起点 | 目标构型 gate → 违规拒绝 |
| 拖动/示教/零力矩/阻抗 | 仅 5Hz 监护红牌 |

**三重不影响原有功能的保险**：
1. 总开关（顶栏「自碰撞」复选框 / `POST /collision {on}`），关掉后所有入口行为与改造前一致
2. fail-open：checker 构建/检查任何异常 → 放行+日志，碰撞模块故障≠面板故障
3. 所有规划仍在既有后台线程（`_spawn`），UI 不卡
