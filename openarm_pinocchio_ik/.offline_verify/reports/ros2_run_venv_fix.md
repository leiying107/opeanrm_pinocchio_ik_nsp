# ros2 run FK NumPy/Pinocchio Fix Report

**Date:** 2026-07-24
**Package:** openarm_pinocchio_ik v0.1.0
**Issue:** Console scripts loading incompatible NumPy 2.2.6

---

## 1. Problem Description

### Original Issue
When running `ros2 run openarm_pinocchio_ik fk`, the command failed with:

```
AttributeError: _ARRAY_API not found
Segmentation fault (core dumped)
```

### Root Cause
The console script generated by `colcon build` had a shebang pointing to `/usr/bin/python3`:

```bash
#!/usr/bin/python3
```

This caused the script to use the system Python, which loaded NumPy 2.2.6 from `/usr/local/lib/python3.10/dist-packages/`. Pinocchio 3.9.0 (from ROS2 Humble) was compiled against NumPy 1.x and failed with the NumPy 2.x ABI.

### Diagnosis Summary
| Item | Original State | Problem |
|------|---------------|---------|
| Console script shebang | `#!/usr/bin/python3` | Uses system Python |
| System NumPy | 2.2.6 | Incompatible with Pinocchio |
| Venv NumPy | 1.26.4 | Compatible, but not used |
| Pinocchio | 3.9.0 | Requires NumPy 1.x |

---

## 2. Resolution Method

### Approach: Rebuild with Venv Python

Instead of modifying source code or console scripts directly, the package was rebuilt using the virtual environment's Python interpreter. This ensures setuptools generates console scripts with the correct shebang.

### Steps Executed

#### 1. Backup Old Build
```bash
mv .offline_verify/build → .offline_verify/archive/build_system_python_20260724_101820
mv .offline_verify/install → .offline_verify/archive/install_system_python_20260724_101820
mv .offline_verify/log → .offline_verify/archive/log_system_python_20260724_101820
```

#### 2. Activate Venv and Rebuild
```bash
source /opt/ros/humble/setup.bash
source .offline_verify/venv/bin/activate
python -m colcon build --packages-select openarm_pinocchio_ik ...
```

The key was using `python -m colcon` instead of `colcon` directly, which ensured the virtual environment's Python was used for the build process.

#### 3. Colcon Build Command
```bash
python -m colcon \
    --log-base "$PWD/.offline_verify/log" \
    build \
    --base-paths "$PWD" \
    --build-base "$PWD/.offline_verify/build" \
    --install-base "$PWD/.offline_verify/install" \
    --packages-select openarm_pinocchio_ik \
    --symlink-install \
    --event-handlers console_direct+
```

## 6. Convenience Script

### Location
```
.offline_verify/run_offline_fk.sh
```

### Usage
```bash
cd /ros2_ws/openarm_pinocchio_ik
./.offline_verify/run_offline_fk.sh --side right --deg 0,-30,0,90,0,45,0
```

### Features
1. Automatically sources ROS2 Humble
2. Activates the virtual environment
3. Sources the local install
4. Verifies NumPy version (must be 1.x)
5. Verifies Pinocchio is available
6. Runs FK with provided arguments
7. Exits with error if NumPy 2.x is detected
