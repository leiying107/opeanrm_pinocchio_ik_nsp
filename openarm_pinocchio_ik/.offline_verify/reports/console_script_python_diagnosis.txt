PROBLEM IDENTIFIED
------------------
The console script shebang points to /usr/bin/python3 (system Python),
which loads NumPy 2.2.6 from /usr/local/lib/python3.10/dist-packages/.

This causes Pinocchio (compiled for NumPy 1.x) to fail with:
  AttributeError: _ARRAY_API not found
  Segmentation fault

ROOT CAUSE
----------
When colcon build runs with system Python, setuptools generates
console scripts with #!/usr/bin/python3 shebang.

The console script does NOT respect the current shell environment
or virtualenv - it always uses the Python specified in its shebang.

RESOLUTION PLAN
---------------
Rebuild using the venv Python as the build interpreter,
so setuptools generates console scripts with the correct shebang
pointing to .offline_verify/venv/bin/python.
