IMPORT ERROR

AttributeError: _ARRAY_API not found
Segmentation fault when importing pinocchio

CAUSE: Pinocchio compiled with NumPy 1.x ABI is incompatible
       with NumPy 2.2.6 ABI changes.

ROOT CAUSE ANALYSIS
------------------
1. ROS2 Humble Pinocchio was built against NumPy 1.x
2. User-installed NumPy 2.2.6 in /usr/local/lib/python3.10/dist-packages/
3. Python loads user site-packages BEFORE dist-packages
4. NumPy 2.2.6 is loaded instead of system NumPy 1.21.5
5. Pinocchio fails to import due to ABI mismatch

RESOLUTION OPTIONS
------------------
Option 1: Disable user site-packages with PYTHONNOUSERSITE=1
Option 2: Create isolated venv with numpy<2
Option 3: Rebuild Pinocchio with NumPy 2.0+ (NOT ATTEMPTED)
