MOVE_JOINTS BEHAVIOR (from move_joints.py)
-------------------------------------------
- Reads current /joint_states
- Builds interpolated trajectory from current to target
- Publishes to /{side}_joint_trajectory_controller/joint_trajectory
- Requires running bimanual launch (reads /joint_states)
- NO dry-run mode

HOME BEHAVIOR (from home.py)
----------------------------
- Shortcut for move_joints with target=zeros(7)
- Same dependencies and behavior as move_joints

FK CLI BEHAVIOR (from fk.py)

- Reads no topics, publishes nothing
- Input: 7 joint angles
- Output: EE position and orientation (xyzw quaternion)
- SAFE for offline validation
